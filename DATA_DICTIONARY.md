## Data rules

- Snapshot: `DATA/CAR_DATA_FINAL/`; schemas and row counts follow `manifest.json`.
- Missing profiles include nulls, blank text, and non-finite numbers. Color placeholders (`none`, `null`, `unknown`, `n/a`, `na`, `not applicable`) and seating `--` are missing. Examples exclude missing values.
- Safety profiles treat star-rating `0`/`Not Rated` as missing; zero rollover values are missing when the paired rating is unavailable. Saved values remain unchanged by profiling.
- Numeric/date conversion failures become null; fractional integers round with ties away from zero. Complaint/recall JSON expands to columns; nested values remain JSON text. Safety fields pivot by query/variant.
- Manual eligibility exclusion (2026-10-25): JN1BJ1CV7LW262847, 123686, WBAGK2324TDH67073, 3C7WRSAL3KG618855, 1FTEW1CP3LFC54483, 1FTEW1E4XLKE38250. These six user-reviewed listing errors are omitted from dashboard queries and future price-model populations, and from future exports. The existing snapshot profiles above remain unchanged; no source rows were deleted. Saved models/overall metrics predate this rule and require retraining to remove training influence.
- Export excludes null mileage and review-file VINs with price/cohort-median ratio >2 or <=0.75, or mileage/cohort-median ratio >20. Model loading repeats these exclusions and requires positive `price`.
- Cohort fields are separate vPIC `ModelYear`, `Make`, `Model`, `Trim`. Listing linkage uses lowercase `vin`, never decoder `VIN`.
- Listing dates span 2010-11-03 to 2020-09-13; price-observation dates remain unverified. YouTube publication/update strings use `MM-DD-YYYY`; historical text versions and engagement remain unverified.
