## Data rules

Derived exports below leave the six source schemas unchanged. Saved artifacts retain their recorded policy/schema; changed predictor selections require compatible retraining. Workflow commands belong in the [README](README.md).

- Snapshot: `DATA/CAR_DATA_FINAL/`; schemas and row counts follow `manifest.json`.
- Missing profiles include nulls, blank text, and non-finite numbers. Color placeholders (`none`, `null`, `unknown`, `n/a`, `na`, `not applicable`) and seating `--` are missing. Examples exclude missing values.
- Safety profiles treat star-rating `0`/`Not Rated` as missing; zero rollover values are missing when the paired rating is unavailable. Saved values remain unchanged by profiling.
- Numeric/date conversion failures become null; fractional integers round with ties away from zero. Complaint/recall JSON expands to columns; nested values remain JSON text. Safety fields pivot by query/variant.
- Manual eligibility exclusion (2026-10-25): JN1BJ1CV7LW262847, 123686, WBAGK2324TDH67073, 3C7WRSAL3KG618855, 1FTEW1CP3LFC54483, 1FTEW1E4XLKE38250. These six user-reviewed listing errors are omitted from dashboard queries and future price-model populations, and from future exports. On 2026-11-11, VIN `3C7WRSAL3KG618855` (recorded mileage 99,999,988) was also removed from the saved listing Parquet. Its refreshed profiles contain 2,792,998 rows, with maximum recorded mileage 1,225,238; other manual exclusions remain pending in this snapshot. The manifest records this single-row correction. SQLite source rows remain unchanged. Saved models/overall metrics predate this rule and require retraining to remove training influence.
- Export excludes null mileage and review-file VINs with price/cohort-median ratio >2 or <=0.75, or mileage/cohort-median ratio >20. Model loading repeats these exclusions and requires positive `price`.
- Cohort fields are separate vPIC `ModelYear`, `Make`, `Model`, `Trim`. Listing linkage uses lowercase `vin`, never decoder `VIN`.
- vPIC aligns to the retained listing population after listing exclusions. Each listing VIN has exactly one row, including null source fields when no decode exists. On 2026-11-11, 2,792,905 matched source records and 93 missing-decode placeholders give 2,792,998 aligned rows; 206,970 out-of-population source records were omitted. Equal row counts measure population alignment, not complete or successful decoding; the manifest records matched and missing source records. All-null source fields remain missing on repeated alignment. No listing make, model, trim, or year is substituted for a missing decoded value. Other source tables retain their own complaint, campaign, tested-variant, or comment grains. Saved model and discovery artifacts are not regenerated by alignment.
- Listing dates span 2010-11-03 to 2020-09-13; price-observation dates remain unverified. YouTube publication/update strings use `MM-DD-YYYY`; historical text versions and engagement remain unverified.
